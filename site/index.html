Let AI assistants book salon appointments.
The customer approves every booking.

Cresavo Gateway is the agent-facing front door to Cresavo salons. Your assistant finds services and free times, proposes a booking, and books only what the customer approved. The gateway stores nothing and decides nothing. The salon does.

Connect

MCP

Streamable HTTP, one JSON-RPC message per request.

{{ORIGIN}}/api/v1/mcp

Add it to any MCP client that supports remote servers and custom headers:

{
  "mcpServers": {
    "cresavo": {
      "type": "http",
      "url": "{{ORIGIN}}/api/v1/mcp",
      "headers": { "Authorization": "Bearer ${CRESAVO_AGENT_KEY}" }
    }
  }
}

REST

The same operations as plain HTTP, described in OpenAPI 3.1.

{{ORIGIN}}/api/v1
curl "{{ORIGIN}}/api/v1/services?business=demo" \
  -H "Authorization: Bearer $CRESAVO_AGENT_KEY"

Discovery for agents: /.well-known/usp and /llms.txt.

Credentials. Agent credentials are issued by the salon provider, never by the gateway. Send them in the Authorization header only. Never put them in URLs, prompts or chat. To request demo access, open an issue.

How a booking happens

Third-party writes are propose and approve. Your assistant never holds the customer's approval link.

  1. 1

    Find

    list_services and get_availability return services, prices in öre, staff and bookable starts.

  2. 2

    Propose

    create_proposal prepares exact terms: service, staff, start, duration and price. Nothing is reserved yet.

  3. 3

    Customer approves

    The salon sends the customer a private link to its consent page. Approval creates a mandate locked to those exact terms.

  4. 4

    Book

    Poll get_proposal for the mandateId, then call create_booking with a stable idempotency key.

Price or terms changed

The mandate no longer matches. mandate_denied, nothing is booked.

Slot taken

Someone else booked first. slot_unavailable, propose a new time.

Timeout or 503

Retry with the same idempotency key. You get the original booking, never a duplicate.

Every limit answers 429 with Retry-After. The salon applies its own limits per agent and per customer on top. Errors use one shape: {"apiVersion":"v1","error":{"code","message"}}.

What the gateway never does

  • Invent a booking result. No salon answer means no booking.
  • Reuse an access check across requests.
  • Forward browser sessions, cookies or client IP headers.
  • Store or log credentials, customer data or request bodies.
  • Take payments, export data or bulk delete.
