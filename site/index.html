Built so an assistant can’t overreach

Consent built in
Every booking runs on a mandate the customer approved. Change price, staff or time and it no longer counts.
No database
Only in-memory rate-limit counters keyed by IP. No logs of bodies or credentials. The salon owns calendar, data and every decision.
Standard protocols
MCP over Streamable HTTP for agents, REST with OpenAPI 3.1. Same operations on both.
Safe to retry
The same idempotency key returns the original booking, never a duplicate.

Read tools are safe to call freely; write tools always end at the customer. USP-style aliases (usp_services_list, usp_availability_query, usp_bookings_create and more) map to the same inputs; full USP conformance is not claimed.

What the gateway never does.

Tested, not promises. Read the security model.

  • Invent a booking result. No salon answer means no booking.
  • Reuse an access check across requests.
  • Forward browser sessions, cookies or client IP headers.
  • Store customer data, or log credentials or request bodies.
  • Take payments, export data or bulk delete.

Honest answers.

Does this work in ChatGPT or Claude today?

The gateway speaks MCP, the open protocol these assistants use to connect tools, plus plain REST. Any client that can call a remote MCP server with a bearer token can use it. We don’t claim partnership or certification with any assistant, and the names on this page belong to their owners.

Can an assistant book without me?

No. Every booking needs a mandate the customer approved on their own device. If anything in it changes, the salon refuses the booking.

Does the gateway store my data?

No database. It keeps only short-lived rate-limit counters keyed by IP, and never logs request bodies or credentials. The salon owns the calendar and customer data.

Can I use it with another booking system?

Yes, if it implements the provider contract. Cresavo is the first. There’s a conformance check to prove it.

How do I get access?

Credentials are issued by the salon, never by the gateway. For demo access, open an issue.
